# Kshitiz Bhurtel — Portfolio

This is a Vite + React + TypeScript + Tailwind project for my portfolio.

## Quick start

1. Install deps
   ```bash
   npm i
   ```

2. Run locally
   ```bash
   npm run dev
   ```

3. Build for static hosting
   ```bash
   npm run build
   npm run preview
   ```

4. Deploy
   - Upload the `dist/` folder to Netlify, Vercel (static), Cloudflare Pages, GitHub Pages, or any static host.

## Customize

- Edit `src/data/profile.ts` for your profile, links, skills, and experience.
- Edit `src/data/projects.ts` to add or reorder projects.
- Replace `public/Kshitiz_Bhurtel_Resume.pdf` with your actual resume file.
